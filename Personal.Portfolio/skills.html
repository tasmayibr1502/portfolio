Academic Project • Deep Learning Research

AI-Based Chest X-Ray Detection & Classification

Healthcare UI/UX • Computer Vision • Python / CNN

An academic exploratory project developed to investigate how convolutional neural networks (CNNs) can classify common pulmonary conditions (such as consolidation, effusion, and pneumonia) from chest radiographs, paired with an ethical, transparent physician-assistance dashboard concept.

Python PyTorch / TensorFlow CNN Architecture Image Preprocessing Diagnostic UI Concept
Academic Problem Statement

Radiologists face significant cognitive workloads when evaluating voluminous radiographic datasets under acute time pressure. The academic objective was to evaluate transfer learning models to assist—not replace—clinicians by flagging probable abnormalities for prioritized review.

Academic Scope: This project is an exploratory college study. It avoids unsubstantiated clinical efficacy claims and is explicitly framed as an academic learning milestone in computer vision.

Technical Pipeline & Methods
  • Data Augmentation: Normalized chest X-ray images, applied random rotation, zooming, and contrast enhancement to prevent model overfitting.
  • Model Architecture: Evaluated convolutional neural networks (ResNet-50 / DenseNet backbones) with binary cross-entropy loss functions.
  • Confidence Metrics: Outputted softmax classification probabilities alongside localized heatmap region suggestions.
UI/UX Design Considerations
  • Trust & Explainability: Designed clean bounding indicators with explicit percentage confidence labels so medical personnel can verify reasoning.
  • Visual Calm: Used warm ivory and soft muted tones instead of stark neon alerts to minimize screen fatigue in hospital diagnostic rooms.
  • Accessibility: High-contrast radiological viewing mode with non-color-dependent anomaly flags.
Concept Project • UI/UX Case Study

A Better Way to Stay Organized

Productivity Platform • Interaction Design • Wireframing

A conceptual productivity and mindfulness dashboard born out of personal frustration with overly complex, stressful task management applications. It emphasizes intentional daily planning, gentle habit tracking, and cognitive breathing room.

User Research Information Architecture Figma Wireframing Interaction Design Heuristic Evaluation
UX Challenge & Insight

Most productivity tools overwhelm students with infinite backlogs, aggressive red alert badges, and tedious tagging systems. User interviews revealed that learners felt more guilt than motivation when opening their daily planner.

Design Hypothesis: By limiting daily active priorities to three focal tasks and integrating calming visual feedback, users achieve higher task completion rates with lower anxiety.

Design Methodology
  • Calm Aesthetics: Warm ivory and soft beige palettes replace clinical harshness, creating a welcoming digital morning routine.
  • Mindful Habit Rings: Concentric circular progress indicators provide gentle progress visual cues rather than stressful binary checkboxes.
  • Time-Blocking Simplicity: Drag-and-drop daily agenda layout that adapts dynamically to unexpected schedule changes.
User Feedback & Next Steps
  • Heuristic Review: Feedback praised the visual hierarchy and uncluttered navigation while suggesting keyboard shortcuts for rapid task entry.
  • Future Prototype: Planned interactive front-end prototype utilizing local storage (IndexedDB) for fully offline client-side task persistence.
Active Project • Handcrafted Front-End

Creative Portfolio Website

Visual Identity • Semantic HTML5 • Vanilla JavaScript

The very website you are experiencing now. Designed and implemented from scratch without heavy frameworks to demonstrate core web standards: semantic architecture, CSS custom properties, responsive grid typography, and accessible UI interactions.

HTML5 Semantic CSS3 Custom Tokens Vanilla JS WCAG Accessibility Editorial Typography
Design System Philosophy

Inspired by high-end editorial publications and warm ceramic arts, this website rejects generic templates. A strict 6-color palette (Ivory, Beige, Terracotta, Deep Brown, Olive, Warm White) is organized into centralized CSS custom properties for effortless consistency and maintainability.

Typography Pairing: Cormorant Garamond lends organic elegance to editorial headlines, while DM Sans provides crisp, legible sans-serif readability for interface controls.

Technical Implementation
  • Zero Build Dependencies: Implemented purely with standard HTML5, CSS3, and modern vanilla JavaScript for instant local execution without Node build tools.
  • Fluid Layouts: CSS clamp() functions ensure typography and padding scale smoothly between mobile viewports and large desktop monitors.
  • Accessible Modals & Drawers: Semantic aria-expanded and keyboard Escape listeners maintain compliance with WCAG usability guidelines.
Academic Significance
  • Demonstrable Competency: Validates 5th-semester BCA skills across responsive layouts, state handling, form validation, and creative direction.
  • Continuous Evolution: Serves as an active living sandbox for testing new web APIs, CSS view transitions, and design experiments.
